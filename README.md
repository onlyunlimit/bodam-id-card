# onlyunlimit

**SGIA · 국가 각성자 통합관리청** 창작 세계관 포털.

## 로컬 미리보기

Node.js 22 이상에서 실행합니다. 홈페이지 실행에는 외부 패키지가 필요하지 않습니다.

```sh
npm run dev
```

http://localhost:4173 에 접속합니다. 명령 실행 시 공개 파일을 `dist/`에 새로 빌드합니다. 소스를 수정했다면 서버를 다시 시작해 반영합니다. 저장소 루트를 Live Server나 `python -m http.server`로 서빙하지 마세요. **웹 루트는 반드시 `dist/`로 지정합니다.**

```sh
npm run build       # 공개 배포 폴더 생성
npm test            # 시간표, 집계, 공개 파일 검증
npm ci              # 브라우저 테스트 도구 설치
npm run test:browser # 설치된 Google Chrome으로 실제 상호작용 검사
```

## 파일 구분

| 위치 | 용도 | Git / 배포 |
| --- | --- | --- |
| `index.html`, `assets/` | SGIA 홈페이지와 선별된 소개 데이터 | 공개 |
| `monster.html`, `sgia.html`, `team.html` | 기존 괴물·등록증·팀 제작 도구 | 공개, 기존 주소 유지 |
| `bodam.html`, `school/`, `character/`, `idcard/` | 기존 보담 캐릭터 콘텐츠 | 공개, 별도 아카이브 |
| `quote.html`, `setlog.html`, `bgm/` | 기존 창작 도구와 리소스 | 공개 |
| `caveduck/` | MD 원본, 로어북, 프롬프트 | 로컬 전용, Git 무시, 배포 제외 |
| `private/personal/` | `jy.html`, 개인 PNG 21개 및 JPEG 1개 | 로컬 전용, Git 무시, 배포 제외 |
| `dist/` | 허용 목록으로 만든 공개 웹 루트 | 생성물, Git 무시 |

개인 파일은 삭제하지 않고 원본 그대로 이동했습니다. 로컬 전용 폴더는 새 Git 복제본에 포함되지 않으므로 별도로 백업해야 합니다.

### 비공개의 범위

- GitHub는 같은 저장소 안에서 특정 파일만 private으로 지정할 수 없습니다. `.gitignore`와 빌드 허용 목록으로 앞으로의 커밋 및 배포에서 원본·개인 자료를 제외합니다.
- **이미 커밋된 `jy.html`과 개인 이미지는 기존 Git 기록에 남아 있습니다.** 이번 작업은 원격 저장소의 공개 상태, 과거 기록, 현재 배포 사이트를 변경하지 않습니다. 과거 자료까지 비공개로 하려면 원격 저장소 자체의 가시성 및 기존 배포를 별도로 정리해야 합니다.
- 직원 뷰는 세계관 체험용 전환입니다. 인증이나 보안 장치가 아니며 `assets/characters.js`의 소개 데이터는 공개 파일입니다. 실제 비공개 원문, 성인 설정, 프롬프트나 메타 지시는 포함하지 않습니다.
- `package.json`의 `private: true`는 npm 패키지 발행 방지 설정으로, GitHub 저장소 비공개 설정과는 별개입니다.

## 구성과 조작

- 외부인 뷰어가 매번 기본값입니다. 코드네임과 실루엣을 표시하고, 직원 뷰로 전환하면 실제 이미지와 선별한 상세 기록이 열립니다.
- 5개 부서의 21명과 외부 단체 ORPÉ의 에이지 1명을 분리했습니다. 팀 필터, 검색, 상세 모달을 제공합니다.
- 카드 클릭 / Enter / Space로 앞뒤 전환, 가로 드래그로 회전, 0.8초 길게 누르면 연결된 캐릭터 페이지로 이동합니다. 별도 링크 버튼도 제공하며 모바일의 세로 스크롤은 유지됩니다.
- 활동 표시는 `Asia/Seoul` 시각과 원본 일과표를 사용합니다. 휴식·식사·빈 시간대에는 활동 중으로 표시하지 않습니다. 비콘은 09:00–18:30 업무표, 오리진·실드·헌터 크루는 각 팀의 일과표를 따릅니다. 빈조 개인의 아침 훈련은 부서 전체 근무로 계산하지 않습니다. 오르페는 에이지의 알려진 일정만 표시합니다.
- 게이트·괴물·사건 발생·미등록 각성자·테러 기록은 가상 데이터입니다. 직원 뷰에서 신고를 추가하거나 도장으로 해결하고 취소할 수 있습니다. 집계·레이더가 같은 기록에서 갱신됩니다. 최대 100건을 브라우저에 보관하며 임의로 기존 기록을 삭제하지 않습니다.
- BGM은 Web Audio로 합성한 잔잔한 앰비언트 음향입니다. 클릭 전에는 소리가 나지 않습니다.
- 관제실 / 현장 단말 / 문서 열람 스타일 및 모션 끄기, 기기 동작 줄이기를 지원합니다. 모션을 끄면 뉴스 자동 갱신도 멈추며 수동 새로고침은 가능합니다.
- 뉴스는 45초마다 바뀌는 세계관 가상 브리핑입니다. 시간은 실제 한국 시각입니다.
- 날씨는 서울 기준 [Open-Meteo API](https://open-meteo.com/en/docs)를 이용하며 15분마다 재조회합니다. 조회 실패·오래된 응답은 온도 대신 연결 대기로 표시합니다. 인물 이미지는 원본 소개에 지정된 Caveduck/Google Storage 이미지를 사용하며 실패하면 대체 실루엣을 표시합니다.

## 배포와 이름 변경

프로젝트 표기와 패키지 이름은 **onlyunlimit**입니다. 로컬 디렉터리 및 GitHub 저장소 이름은 아직 `bodam-id-card`이며 원격 URL도 그대로입니다. 저장소 이름은 이후 GitHub에서 `onlyunlimit`으로 변경하고 remote를 갱신할 수 있습니다. 새 홈페이지 링크는 상대 경로라 프로젝트 경로 변경에 대응합니다.

`.github/workflows/pages.yml`은 **수동 실행 전용**입니다. 추후 GitHub Pages의 Source를 **GitHub Actions**로 설정하고 이 워크플로를 실행하면 `dist/`만 배포합니다. 브랜치 루트를 직접 배포하지 않습니다. 브랜치 푸시만으로는 배포되지 않으며, 배포하려면 워크플로를 별도로 실행해야 합니다.
